# ShinkiEMU Manager 0.1.0-beta.6

Musica の手動セーブ、クイックセーブ、オートセーブは、eden/Perseus 本来の `.sav` スロットと対応する `.png` サムネイルを使用します。旧ベータ版の `.asav` ファイルとは互換性がなく、旧ディレクトリにそのまま残します。読み込み、変換、移動、削除は行いません。

Musica は Android と実験的な OHOS に加え、実機ターゲットと両シミュレーターターゲットの iOS Manager に静的に組み込まれます。iOS では動的コアの単独インストールをサポートしません。統合リリースには、その exact-head でのビルド、パッケージ、署名、ネイティブ依存関係、対応ソースの確認が必要です。独立した移植版の結果は統合版の確認を代替しません。

Android Manager は ARM64 と x86_64 に RFVP、Siglus、Musica、Artemis、Impacto、Ren’Py の6コアを組み込みます。KiriKiri は含まれず、Android の静的組み込みは後続の Manager リリースに向けて開発中です。単独の Android コア ZIP は Manager での利用を保証しません。既存の iOS コア構成を維持し、開発中の KiriKiri/Ren’Py iOS 移植は含みません。

外部コアパッケージは元の upstream ref/commit とアダプターの識別情報を保持します。本版 Manager はこの識別情報付きパッケージとカタログに対応し、beta.5 以前は変更のない旧パッケージとカタログを引き続き使用します。

デスクトップの「出力先を選択」は OS 標準のフォルダー選択画面を開きます。親フォルダーを選び、新しく作る `localized-output[-N]` のパスを確認してください。選択時にはフォルダーを作らず、変換成功時にだけ公開します。既に使用されているパスは上書きしません。

変換結果の profile は必要なコアのネイティブ機能を指定できます。Manager はゲームの追加や設定の保存前に実際のロード済み descriptor を確認し、起動前にも保存された receipt を確認します。機能が不足すればコアの更新を案内し、不正な形式や未知のビットは拒否します。従来の profile に追加要件はありません。

Sakura レシピ 0.2 はネイティブ GBK のスクリプトとリソース名、明示的な HanaMinA 優先フォントを使い、旧ランタイム翻訳テーブルは使いません。スクリプト別セーブ分離と設定フォント優先に対応した新しい RFVP コアが必要です。コアを更新してから、別の新しいディレクトリへ変換してください。既存の変換結果は書き換えません。新しいスクリプト ID では旧日本語版や外部翻訳テーブル版のセーブ・既読を再利用しません。元の字幕スタイルとローカルフォント入力は保持します。

OHOS HAP は引き続き実験的な OpenHarmony SDK テスト PKI 署名パッケージです。デバイス、エミュレーター、ゲーム、アカウントの起動確認は免除されており、市販デバイスへのインストール可能性は未確認です。公開する各プラットフォームのパッケージには対応ソースと依存ライブラリの通知を添付します。公開済み Manager beta4 と beta5 の成果物は変更しません。
