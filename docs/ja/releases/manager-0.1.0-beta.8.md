# ShinkiEMU Manager 0.1.0-beta.8

新しい Musica パッチには Musica コア beta.5 以降が必要です。Manager は実際に読み込んだコアのネイティブ機能を確認し、不足する場合は更新を案内します。Yorino は機能ビット 256 と 512 の両方を必要とします。

オンラインカタログとローカル Luau/ZIP パッチは、実行、リリース指紋の照合、トランザクションを共用します。既定では別の新しいディレクトリに出力し、元の場所への上書きではバックアップと復元を利用できます。パッチはリソースを変換し、EXE の変更や新規作成はできません。patches-v2 の公開後も、旧 Manager は維持された v1 カタログと旧スクリプトを読み込みます。

本版は更新確認を追加し、CLI、バージョン情報画面、更新リクエスト、パッケージの識別にコンパイル時の製品バージョンを使用します。beta.7 の既知の問題として、公式 Windows バイナリは内部版を beta.6 と報告します。公開済み beta.7 タグと添付ファイルは変更せず、旧版の識別にはリリースページを使用してください。

コアのバージョン番号は Manager の beta 番号とは独立しています。新しいパッチを使う前に必要なコアを更新してください。各プラットフォームのパッケージには対応ソースと元の依存ライセンスを添付します。Android は正式なリリース証明書、macOS/iOS は ad-hoc 署名、OHOS HAP は OpenHarmony SDK テスト PKI を使用します。デバイス起動確認は免除されており、OHOS の市販デバイスへのインストール可能性は未確認です。
